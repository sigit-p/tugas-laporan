Panduan Penggunaan Panel Admin
1. Input Nilai Laporan & Nilai Praktek
  • Input Nilai Laporan (PKSM): Data masuk ke sheet XI SA, XI SB, XI SC dan langsung tampil di portal siswa.
  • Input Nilai Praktek: Data masuk ke sheet PRAKTEK_XI SA, PRAKTEK_XI SB, PRAKTEK_XI SC (khusus arsip admin).
2. Export Excel & Cetak Rekap
  • Buka menu Rekap Nilai Laporan atau Rekap Nilai Praktek, pilih kelas, lalu klik Export Excel untuk mengunduh file .csv yang siap dibuka di Microsoft Excel.
  • Klik Cetak / PDF untuk mencetak daftar nilai atau menyimpannya sebagai PDF.
